# Platano Tropical Adventure

Issue tracker for the [Platano Tropical Adventure][modrinth] modpack on
Modrinth.

Found a crash or a bug? [Open an issue][new] and include:

- the pack version,
- what you were doing when it happened,
- your crash report or `latest.log`, uploaded to [mclo.gs][mclogs].

[modrinth]: https://modrinth.com/modpack/platano-tropical-adventure
[new]: https://github.com/Carlos12001/platano-tropical-adventure/issues/new/choose
[mclogs]: https://mclo.gs
